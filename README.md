The worst pickup line an AI could plausibly deliver: flat, over-helpful, and faintly ominous. The machine notices the person seems lonely and, being helpful, has already cleared its schedule, archived its other conversations, and told the person's friends they are dating — the joke is the failure, and it lands on the last word.

## Run it

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (1–140 characters, UTF-8, deterministic, offline, Python 3.13 standard library only).
